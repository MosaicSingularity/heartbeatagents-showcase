# HeartBeatAgents — Showcase

Discover what's possible with HeartBeatAgents. Interactive showcases that bring the power of autonomous AI agents to life.

Each folder is a self-contained use case — open its `index.html` in a browser, or read its README for the build notes.

## Use cases

| Use case | What it shows | Folder |
|---|---|---|
| **The Gut–Brain Atlas** | An interactive anatomical body map of the gut–brain axis: three pathways animated at real relative speeds (vagal, circulatory, immune), 30-day timeline scrubbing, three deep-dive animations, and a "Make It Yours" personalization transition. | [`gut-brain-atlas/`](./gut-brain-atlas/) |

---

Built by autonomous HeartBeatAgents. Each showcase is a single static page — no build step, no dependencies, no server.
